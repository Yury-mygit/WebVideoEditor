# SlideSub Web — видео из картинок и субтитров

Веб-версия приложения из ТЗ «SlideSub» (`TZ_SlideSub.docx`, v0.1): длинный ролик (~1:30:00) из нескольких
статичных изображений, поверх — субтитры с точными таймингами. Рендер — FFmpeg на сервере.

## Состав

| Папка     | Что внутри |
|-----------|------------|
| `shared/` | Типы проекта, разбор/запись SRT, ASS, TXT, генерация ASS для рендера, проверки (ФТ-14, ФТ-26), тесты |
| `server/` | Node + Express: хранение проектов и файлов, рендер через FFmpeg, прогресс по SSE |
| `web/`    | React + Vite: редактор (сцены, превью, стиль, таймлайн, таблица реплик, окно сборки) |

Принцип из ТЗ сохранён: приложение не обрабатывает видео само, а формирует из проекта ASS-файл и команду FFmpeg.

## Запуск

Нужен Node.js 20+. FFmpeg ставится npm-пакетом `@ffmpeg-installer/ffmpeg` (бинарник приходит из npm-реестра,
отдельно ничего скачивать не нужно).

```bash
npm install
npm run dev        # сервер API на :3001 + Vite на http://localhost:5173
```

Сборка и запуск одним процессом (сервер раздаёт собранный фронтенд):

```bash
npm run build
npm start          # http://127.0.0.1:3001
```

Проверки:

```bash
npm test           # юнит-тесты shared (SRT/ASS/TXT, тайминги, проверки)
npm run typecheck
```

### Инструкция для пользователя

Страница `/instruction` (кнопка «? Инструкция» в редакторе) — пошаговая инструкция в картинках.
Скриншоты лежат в `web/public/guide/`, демо-файлы (4 фото и SRT) — в `web/public/guide/demo/`.
После изменений интерфейса картинки пересоздаются автоматически:

```bash
npm run guide:demo    # демо-фото и SRT (Python + Pillow), обычно не нужно
npm run guide:shots   # сборка, прогон сценария в headless Chrome, новые скриншоты
```

Скрипт поднимает отдельный сервер на порту 3102 с временной папкой данных, рабочие проекты не трогает.

### Переменные окружения сервера

| Переменная    | По умолчанию | Назначение |
|---------------|--------------|------------|
| `PORT`        | `3001`       | Порт API |
| `HOST`        | `127.0.0.1`  | Интерфейс; для удалённого сервера — `0.0.0.0` |
| `DATA_DIR`    | `./data`     | Проекты, загруженные файлы, готовые ролики, логи |
| `FFMPEG_PATH` | из npm-пакета | Свой FFmpeg (на Linux-сервере лучше системный свежий) |
| `FONTS_DIR`   | —            | Папка со шрифтами для libass (на сервере нужны те же шрифты, что выбраны в стиле) |

## Данные

```
data/
  projects/<id>/project.json   — проект (формат из раздела 8 ТЗ)
  projects/<id>/assets/        — картинки (имена в проекте относительные)
  projects/<id>/renders/       — готовые MP4; во время рендера пишется *.part.mp4 и переименовывается в конце
  logs/render-*.log            — полная команда и вывод FFmpeg по каждому рендеру
```

## Что сделано (этап 1 — MVP, плюс часть этапа 2)

- Проекты: список, создание, автосохранение на сервер, предупреждение при закрытии вкладки с несохранёнными
  изменениями, отмена/повтор (Ctrl+Z / Ctrl+Y).
- Сцены (ФТ-10…15): загрузка JPG/PNG/WEBP кнопкой и перетаскиванием, замена картинки с сохранением тайминга,
  удаление, порядок перетаскиванием, длительность вручную, «Поделить поровну» с точностью до кадра, предупреждение
  о расхождении суммы и «Подогнать последнюю»; подгонка: обрезать / вписать с цветом полей / растянуть.
- Субтитры: импорт SRT, ASS, TXT (кодировка UTF-8 или Windows-1251 определяется сама), экспорт SRT и ASS,
  таблица с правкой на месте (виртуализирована под тысячи реплик), добавление и удаление, сдвиг таймингов
  выделенных или всех, подсветка замечаний (пересечения, короче 1 с, длинная строка, за пределами ролика),
  фильтр «только с замечаниями», Shift+Enter — ручной перенос строки.
- Стиль: шрифт, размер, жирный/курсив, цвет, обводка, тень, подложка с прозрачностью, позиция, выравнивание,
  отступ, максимальная ширина текста.
- Превью на canvas по тем же правилам, что и libass (размер шрифта, жадный перенос, высота строки);
  воспроизведение без звука, шаг по кадрам, таймлайн с полосами сцен и реплик и масштабами.
- Рендер: 1080p / 720p / 4K, 24–60 fps, H.264, вшитые субтитры; проверка проекта перед сборкой, очередь,
  прогресс и оставшееся время, отмена, скачивание результата, тестовый фрагмент 1 мин с текущей позиции,
  лог в файл, понятное сообщение об ошибке.

## Не сделано (следующие этапы ТЗ)

- Аудио (ФТ-40…42) и звук в превью; переходы crossfade (ФТ-16); отключаемая дорожка субтитров (ФТ-61).
- Разделение и объединение реплик (ФТ-23), поиск и замена (ФТ-25), пресеты стиля (ФТ-33),
  загрузка своих шрифтов .ttf/.otf (ФТ-30), индивидуальный стиль реплики (ФТ-35).
- Для удалённого сервера: авторизация, удаление старых проектов и роликов, шрифты на сервере.
